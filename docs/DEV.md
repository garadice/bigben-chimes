# Big Ben Chimes — developer notes

Dev-facing detail; user-facing text lives in the README.

## Project layout

```
index.html          shell: photo, clock dial badge, 3 buttons, volume row
styles.css          kid-first styles (portrait phone first; see below)
chime.js            PURE logic, no DOM (node-testable): bong counts, quarter
                    marks, event timelines, the quarter scheduler
app.js              DOM wiring: audio pool, gesture unlock, sequencer,
                    scheduler hookup, clock display, volume/mute, __BBC__ hooks
manifest.json       PWA manifest (standalone, portrait, 4 icons)
sw.js               service worker: cache-first shell incl. audio + photo
icons/              4 PNG icons, generated by tools/gen_icons.py (Pillow)
audio/melody.m4a    full Westminster Quarters sequence, 17.67 s (PD, 1945)
audio/melody.ogg    same cut, Vorbis fallback (canPlayType picks per browser)
audio/bong.m4a      single hour strike + decay, 4.10 s (PD, 1945)
audio/bong.ogg      same cut, Vorbis fallback
photo/bigben.jpg    tower photo, 1600x3190 (CC BY 2.5, Diliff)
tools/gen_icons.py  regenerates icons (build-time only, needs Pillow)
tools/chime_test.js headless logic suite: node tools/chime_test.js
LICENSES.md         every non-code asset: source URL + author + license
```

## Hard constraints (same charter as london-boom)

- **Zero build step** — plain HTML/CSS/JS. No framework, no npm runtime.
- **Zero runtime network** — no fetch/CDN/fonts. Everything local, SW-cached.
- **Asset gate** — only separately-licensed open material; every asset needs
  a LICENSES.md entry. Never extract anything from a store-bought app.
- **Cache rule:** bump `CACHE` in sw.js whenever any cached file changes
  (deploy cache-bust). Coder branches ship a sensible name; main bumps at
  merge/release.
- Kid-safe audio: no sudden loud spikes; the bong tail fades out.
- **SW + media gotcha (verified 2026-11-08):** Chrome loads audio/images with
  byte-range requests; answering those with a cached full 200 stalls the
  media element forever (readyState 0, no error). sw.js therefore slices the
  cached body into a real 206 for any Range request — keep that when editing
  the fetch handler.

## Sound model

- Hour bongs = `(hour % 12) || 12` — midnight and noon strike 12 times.
- One recorded bong (`audio/bong.m4a`) is repeated with a 2.0 s gap (card
  spec: realistic 1.5–2 s). A pool of 4 Audio elements cycles so a new strike
  never cuts the previous one's decay.
- Quarter marks: `:15/:30/:45` play the melody alone; `:00` plays melody +
  the correct bong count. **Approximation (documented in LICENSES.md):** the
  real tower plays short distinct phrases per quarter, but no freely-licensed
  recordings of those individual phrases exist — the 1945 recording runs the
  phrases together as one continuous sequence, so it is shipped whole.
- The full-chime timeline (chime.js `fullChimeEvents`): melody at t=0,
  first bong at `melodyDur + gap`, then `gap` apart.

## Quarter scheduler semantics (chime.js `createQuarterScheduler`)

- Injected `now()` (tests) — the app passes `Date.now() + offset`.
- One fire per quarter mark (key `YYYY-MM-DDTHH:MM` of the mark itself).
- Grace window **90 s**: a mark more than 90 s stale (Android froze the tab)
  is consumed silently — no blast from the past; the next fresh mark fires.
- Plain `setEnabled(true)` mid-mark fires the current mark at once
  (deliberate: toggling on gives instant feedback if inside grace).
- `setEnabledQuiet(true)` arms without firing — used at boot (app.js) to
  restore a persisted ON toggle (no mid-mark blast) and in tests.

## Audio unlock (Android Chrome)

First `pointerdown`/`touchend` anywhere plays every player muted and pauses
it; afterwards unmuted `play()` is allowed. Buttons also call `unlock()`
before playing. No autoplay on load.

## Testing

- Logic: `node tools/chime_test.js` (61 checks).
- Browser (manual/agent sweep): serve `python3 -m http.server`, check zero
  console errors, click each button, spy `__BBC__.stats()` / player state,
  shift the clock with `__BBC__.setClockOffset(ms)` to hit quarter marks,
  verify SW + manifest + icons resolve, then stop the server and reload to
  prove offline works.
- `window.__BBC__` exposes playEvents/cancelAll/players/scheduler for tests.
